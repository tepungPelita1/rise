# ✷ Rise

### Today, *pick three.*

A loud, pastel, slightly chaotic task dashboard that only lets you commit to **three things a day.**
Everything else waits in *Later*.

**[→ rise.ajamlab.my](https://rise.ajamlab.my)**  ·  🔒 PIN-locked, it's personal

</div>

---

## Why

Twenty-item to-do lists don't get done. Rise forces the question every morning:
*what are the three that actually matter today?* Finish them, and the rest can wait.

> the more you larp, the less you less larp.

## What's inside

| | |
|---|---|
| 🎯 **Today** | Three slots. That's the whole plan. Suggestions sorted by what's due soonest. |
| 📥 **Inbox → Later** | Dump everything with `Ctrl K`, sort it out when you have a minute. |
| 🌱 **Goals** | Weekly focus plus areas: Study, Build, Life Admin, Self. |
| ✅ **Done + streaks** | A GitHub-style heatmap and a reading streak that keeps you honest. |
| 🔁 **Review** | Weekly look back. Set next week's focus. |
| 🧸 **Playground** | Draggable stickers and a buddy you can poke. Because why not. |
| 🔒 **Lock screen** | 6-digit PIN, frosted glass that splits open, and a full-screen snake game while you're there. |
| 🌙 **Dark mode** | For late-night study sessions. |

## Built with

**SvelteKit** · **Svelte 5** · **SQLite** (`node:sqlite`) · Bricolage Grotesque, Instrument Serif & Space Mono

Self-hosted on a homelab in Docker, served through a Cloudflare Tunnel.

## Design

Playful bento. Pastel cards, chunky black outlines, mixed fonts, stickers everywhere.
Calm enough to work in, loud enough to not be boring. Full spec in [docs/SPEC.md](docs/SPEC.md).
